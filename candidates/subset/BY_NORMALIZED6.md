# Six divsteps indexed by an odd-normalized ratio

Parent: point-X3 `6084b25b81d5b62d81beb9ab1fe2d780667ac40a`. This extends ercumentyildirim's public PR296 table mechanism with a new index reduction. Five six-step lookups produce the same30-step decision matrix. The table is832 entries of64 bits,6,656 bytes; a direct six-step table indexed by both low words would need26,624 entries. All inherited authorship and license notices remain.

For odd f and a group of s divsteps, multiply f and g by the odd inverse of f modulo2^s. The initial residues become1 and g/f. Multiplication by an odd value preserves parity. At each subsequent linear update and division by two, the scaled residues stay equal modulo2 raised to the remaining number of steps. The delta sign and parity decisions therefore remain identical, and the selected integer matrix is unchanged. This concerns the decision sequence only: production still applies the matrix to the original f,g and accumulated coefficients.

For s=6, no lookup is needed to compute the odd inverse. Since f² is1 modulo8, f²*(2-f²)=1-(f²-1)² is1 modulo64. Thus `f*(2-f*f)` is the inverse of f modulo64. Unsigned32-bit wrap preserves these six low bits. Production computes `ratio=(g*f*(2-f*f))&63`, clamps delta to[-6,6] for the lookup, and updates the original delta with the returned exact affine map. The clamp proof is the same finite-step sign argument as the four-/five-step tables. Coefficients have absolute bounds64,64,63,63 and fit signed bytes, decoded with the previously reviewed generic PTX PRMT helper.

The generator exhaustively compares all26,624 direct delta/f/g residue combinations with the normalized table, using integer division and exact coefficients.
