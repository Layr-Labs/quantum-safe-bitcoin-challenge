# Historical research archive

All earlier experiments remain in history-before-four-stage.tar.xz. Extract with `tar -xJf history-before-four-stage.tar.xz` from this research directory. Gzip JSON artifacts were decompressed when added, so extraction restores their original .json names for existing readers. Every member was hashed and verified before the original copy was removed. The mapping and SHA256 values are in split_sha_point/history-archive-manifest.json. Current SHA/point experiment, capture wrapper and live remote status remain directly available. Rebuildable ELF executables were removed with hashes retained.

Previous production snapshots from split_sha_point and split_quad_inverse are now preserved in `previous-production-snapshots.tar.xz`. All eight files were byte-hash verified before removal; see `previous-production-snapshots-manifest.json` for names, hashes, and restoration. No runtime include references these historical snapshots.
